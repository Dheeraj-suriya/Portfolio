## 💻 Run the Project Locally

To run this portfolio project on your local machine, follow these steps.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Dheeraj-suriya/Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd Portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local development URL**

Open the URL displayed in your terminal, typically:

```text
http://localhost:5173
```
